📌 𝐂𝐎𝐑𝐄 𝐂𝐎𝐍𝐂𝐄𝐏𝐓𝐒
[1.] Version Control
◾ Tracks changes in your codebase over time.
[2.] Repository (Repo)
◾ A project folder managed by Git, local or hosted on GitHub.
[3.] Commit
◾ A snapshot of your project at a given time.
[4.] Branch
◾ A parallel version of your project for isolated work.
[5.] Remote
◾ A shared version of your repository, usually hosted on GitHub.

📌 𝐆𝐈𝐓 𝐁𝐀𝐒𝐈𝐂𝐒
[1.] git init - Initialize a new local repository.
[2.] git clone <url> - Clone a repository from GitHub.
[3.] git status - Check working directory status.
[4.] git add <file> - Stage file(s) for commit.
[5.] git commit -m "message" - Commit staged changes.
[6.] git log - View commit history.
[7.] git diff - Show file differences.

📌 𝐁𝐑𝐀𝐍𝐂𝐇𝐈𝐍𝐆 & 𝐌𝐄𝐑𝐆𝐈𝐍𝐆
[1.] git branch - List branches.
[2.] git branch <name> - Create a new branch.
[3.] git checkout <name> - Switch branches.
[4.] git merge <branch> - Merge another branch.
[5.] git branch -d <name> - Delete a branch.
[6.] git rebase <branch> - Reapply commits for cleaner history.

📌 𝐑𝐄𝐌𝐎𝐓𝐄 𝐑𝐄𝐏𝐎𝐒𝐈𝐓𝐎𝐑𝐈𝐄𝐒
[1.] git remote add origin <url> - Connect to GitHub.
[2.] git push -u origin main - Push commits to GitHub.
[3.] git pull origin main - Fetch and merge updates.
[4.] git fetch - Download changes without merging.
[5.] git remote -v - View remote URLs.

📌 𝐖𝐎𝐑𝐊𝐅𝐋𝐎𝐖 𝐄𝐗𝐀𝐌𝐏𝐋𝐄
git init
git add .
git commit -m "Initial commit"

git remote add origin git@github.com:user/repo.git
git push -u origin main

git checkout -b feature/new-ui
git add .
git commit -m "Add new UI"
git push -u origin feature/new-ui

📌 𝐔𝐍𝐃𝐎𝐈𝐍𝐆 & 𝐅𝐈𝐗𝐈𝐍𝐆
[1.] git reset HEAD <file> - Unstage a file.
[2.] git restore <file> - Discard local changes.
[3.] git commit --amend - Modify last commit.
[4.] git revert <hash> - Safely undo a commit.
[5.] git reflog - View complete local history.

📌 𝐒𝐓𝐀𝐓𝐔𝐒 𝐒𝐘𝐌𝐁𝐎𝐋𝐒
◾ M - Modified
◾ A - Added
◾ D - Deleted
◾ U - Unmerged / Conflict
◾ ?? - Untracked file

📌 𝐁𝐄𝐒𝐓 𝐏𝐑𝐀𝐂𝐓𝐈𝐂𝐄𝐒
◾ Commit frequently with clear messages.
◾ Use feature branches.
◾ Pull before pushing.
◾ Protect the main branch.
◾ Maintain good README and docs.

📌 𝐂𝐎𝐍𝐅𝐋𝐈𝐂𝐓 𝐑𝐄𝐒𝐎𝐋𝐔𝐓𝐈𝐎𝐍
[1.] Identify conflict markers (<<<<<<, ======, >>>>>>).
[2.] Resolve conflicts manually.
[3.] Remove markers and save files.
[4.] Stage and commit:
git add <file>
git commit

📌 𝐆𝐈𝐓𝐇𝐔𝐁 𝐒𝐏𝐄𝐂𝐈𝐅𝐈𝐂
◾ Fork - Copy a repository to your account.
◾ Pull Request (PR) - Request code merge.
◾ Issues - Track bugs and tasks.
◾ Actions - Automate CI/CD workflows.
◾ Stars - Bookmark repositories.

📌 𝐒𝐄𝐂𝐔𝐑𝐈𝐓𝐘 𝐓𝐈𝐏𝐒
◾ Never commit secrets or API keys.
◾ Enable 2FA on GitHub.
◾ Use SSH keys.
◾ Review PRs carefully.

📌 𝐒𝐇𝐎𝐑𝐓𝐂𝐔𝐓𝐒 & 𝐓𝐑𝐈𝐂𝐊𝐒

◾ git stash / git stash pop - Save and restore work
◾ git tag -a v1.0 -m "Release 1.0" - Create a tag
